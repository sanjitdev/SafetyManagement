# Ticket Detail (Dispatcher view)

**Route:** `/dispatch/tickets/{ticket_id}`
**Scenario:** Habib the Handler — Runs his ward's morning queue (screen 3 of 7)
**Purpose:** Show Habib everything about a single ticket and let him act on it (route, assign, mark duplicate, escalate).

---

## User Context

Habib opens a ticket from the dashboard. He needs to understand it (what, where, when, who, how severe), then decide what to do (route to a department, assign to a crew, merge duplicates, or escalate). This page is **his decision surface**.

---

## Content & Actions

### Page container

- **Page name:** `dispatch-ticket-detail-page`
- **Language:** Bangla default.
- **Layout:** Two-column desktop (left: ticket content, right: action sidebar). Stacks vertically on tablet and below.
- **Width:** capped at 1280px; content column at 720px on desktop.

### Header

- **`dispatch-ticket-detail-header`** — height 64px, sticky.
- **Left:** back arrow `<`. Routes to `/dispatch` (the dashboard).
- **Center:** "রিপোর্ট #{ticket_id}" / "Report #{ticket_id}".
- **Right:** kebab menu (⋯). Options: Copy ID, Print, Export PDF, Add internal note.

### Left column — ticket content

#### Photo block

- **`dispatch-ticket-detail-photo-block`** — full-width image area.
- "Before" photo if status < resolved.
- "Before / After" pair if status = resolved.
- Tap → opens lightbox with pinch-to-zoom.

#### Metadata block

- **`dispatch-ticket-detail-meta`** — labeled rows:
  - **Category** — e.g., "রাস্তার আলো / Streetlight"
  - **Ward** — "ওয়ার্ড ১৪, মিরপুর / Ward 14, Mirpur"
  - **Address / pin** — short text + small static map snippet (Leaflet, 240×160)
  - **Coordinates** — "23.806°N, 90.368°E" (copy on click)
  - **Submitted** — timestamp + age
  - **Department** — current routing target
  - **Crew** — current assignment (or "Not yet assigned")
  - **Reporter(s)** — count + names (last names masked, e.g., "রহিম এইচ। / Rahim H.")
  - **Dedup group** — if this ticket is the canonical of a group: "৩টি সদৃশ রিপোর্ট একত্রিত / 3 similar reports merged"
  - **SLA window** — "৪৮ ঘণ্টার মধ্যে / within 48 hours"

#### Status trail

- **`dispatch-ticket-detail-status-trail`** — same vertical timeline as citizen view, but with two extra fields visible to dispatchers:
  - Last-updated-by + role.
  - Internal note attached to the step.

#### Reporters block (if dedup > 1)

- **`dispatch-ticket-detail-reporters-block`** — collapsible list of all reporters who contributed to this dedup group, with timestamps and their original notes (if any).

#### Internal notes (dispatcher-only)

- **`dispatch-ticket-detail-internal-notes`** — text list of internal notes added by Habib or other dispatchers. Each note has author + timestamp.
- A "নোট যোগ করুন / Add note" composer at the bottom of the list. Submitting adds the note to the timeline.

#### Citizen note (Rahim's text)

- Quoted block if a citizen added a note. Read-only here.

### Right column — action sidebar (desktop)

Sticky panel on desktop. Stacks above content on mobile.

#### Primary actions

- **`dispatch-ticket-detail-action-route`** — primary button.
  - **Label (BN):** "বিভাগে রাউট করুন"
  - **Label (EN):** "Route to department"
  - Disabled if status = routed/in-progress/resolved.
- **`dispatch-ticket-detail-action-assign`** — primary button (filled, secondary color).
  - **Label (BN):** "ক্রুতে বরাদ্দ করুন"
  - **Label (EN):** "Assign to crew"
  - Tap → opens the Assign-to-Crew modal (see spec).
- **`dispatch-ticket-detail-action-resolve`** — secondary button (outlined).
  - **Label (BN):** "সমাধান হিসেবে চিহ্নিত করুন"
  - **Label (EN):** "Mark as resolved"
  - Tap → opens the Resolve Confirmation modal (see spec).
  - Disabled until status = in-progress and a crew has uploaded an "after" photo.

#### Secondary actions

- **`dispatch-ticket-detail-action-duplicate`** — text link.
  - **Label (BN):** "সদৃশ হিসেবে চিহ্নিত করুন"
  - **Label (EN):** "Mark as duplicate"
  - Tap → opens a small modal to pick the canonical ticket.
- **`dispatch-ticket-detail-action-escalate`** — text link.
  - **Label (BN):** "ঊর্ধ্বতন কর্তৃপক্ষে প্রেরণ"
  - **Label (EN):** "Escalate to higher authority"
  - Tap → opens escalation modal (pick authority level + reason).

#### History strip

- **`dispatch-ticket-detail-history-strip`** — small text block at the bottom of the sidebar.
- "শেষ আপডেট: ১২ মিনিট আগে · হাবিব (ডিসপ্যাচার) / Last updated 12 min ago · Habib (dispatcher)"

## Behavior

### Routing flow

1. Tap "Route to department" → opens department picker (modal).
2. Pick department → confirm → server updates ticket.department; status trail step 2 lights up.
3. Success toast: "বিভাগে রাউট সম্পন্ন / Routed to {department}."

### Crew assignment flow

- See Assign-to-Crew spec.

### Duplicate marking

- Picking a canonical ticket merges the current ticket into that group; reporters get the canonical ticket's status trail.

### Real-time updates

- Polls every 10s while foregrounded. Crew "after" photos and status updates appear without a refresh.

### Photo zoom

- Tap photo → opens lightbox.

### Keyboard shortcuts

- `R` — open Route modal.
- `A` — open Assign modal.
- `D` — open Duplicate modal.
- `Esc` — back to dashboard.

---

## States

### Default (status = new)

All primary actions enabled. History strip shows "রিপোর্ট গৃহীত হয়েছে / Report received" timestamp.

### Routed (status = routed)

"Route to department" disabled. "Assign to crew" still enabled. Status trail shows routing step complete.

### In progress (status = in-progress)

"Assign to crew" disabled. "Mark as resolved" enabled (after "after" photo arrives).

### Resolved (status = resolved)

All action buttons disabled. Status trail shows all 4 steps complete. A small "সমাধান: ২ দিন ৪ ঘণ্টা / Resolved in 2 days 4 hours" badge.

### Duplicate-marked

Ticket detail shows a banner: "এই রিপোর্টটি #{canonical_id}-এ একত্রিত করা হয়েছে / Merged into #{canonical_id}." Link to canonical.

### Network failure

Slim banner at top of content column; actions still enabled (queue locally).

## Success

Habib opens a ticket, sees a pothole report with two merged reporters, assigns it to Crew B with one tap, adds a one-line internal note, moves on. Total time on this page: 90 seconds.

**Emotional outcome:** Habib feels **decisive** — the platform gives him the context he needs to act without rummaging through emails or spreadsheets.
