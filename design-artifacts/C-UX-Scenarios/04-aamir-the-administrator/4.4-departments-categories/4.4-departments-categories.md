# Departments & Categories

**Route:** `/admin/cities/{city_id}/setup/departments`
**Scenario:** Aamir the Administrator — Sets up Chattogram (screen 4 of 7)
**Purpose:** Configure the departments that handle tickets and the categories citizens can report.

---

## User Context

Aamir is configuring Chattogram. He needs to set up the 8 departments (electrical, water, roads, sanitation, etc.) and the categories (streetlight, pothole, drain, garbage, etc.) that map to them. The Dhaka template is pre-populated as a starting point — Aamir will adjust to match Chattogram's structure.

---

## Content & Actions

### Page container

- **Page name:** `admin-city-departments-page`
- **Language:** Bangla default.
- **Layout:** Two-column desktop (left: departments list, right: categories list, with a small mapping panel below). Stacks vertically on tablet.
- **Width:** capped at 1280px.

### Header

- **`admin-city-departments-header`** — height 64px, sticky.
- **Left:** back arrow `<`. Routes to `/admin/cities/{id}/setup` (Basic Info).
- **Center:** "বিভাগ ও ক্যাটাগরি / Departments & categories — {city name}."
- **Right:** save status indicator.

### Template banner

- **`admin-city-departments-template-banner`** — visible at the top of the body.
- **Text (BN):** "ঢাকা টেমপ্লেট লোড হয়েছে — আপনার প্রয়োজন অনুযায়ী সম্পাদনা করুন / Dhaka template loaded — adjust to your needs."
- "ঢাকা টেমপ্লেট প্রতিস্থাপন করুন / Replace with Dhaka template" button (resets to template defaults).

### Departments list (left column)

- **`admin-city-departments-list`** — vertical list of department cards.
- **`admin-city-departments-row-{dept_id}`** — each card shows:
  - Department name (Bangla + English, e.g., "বৈদ্যুতিক বিভাগ / Electrical Department")
  - Contact email
  - Contact phone
  - Number of categories mapped
  - Status pill (Active / Inactive)
- Click row → opens the department editor (inline expansion or modal — see Behavior).

#### Add department

- **`admin-city-departments-button-add`** — at the bottom of the list.
  - **Label (BN):** "+ নতুন বিভাগ"
  - **Label (EN):** "+ Add department"

### Categories list (right column)

- **`admin-city-categories-list`** — vertical list of category cards.
- **`admin-city-categories-row-{cat_id}`** — each card shows:
  - Category icon (small, 24×24)
  - Category name (Bangla + English, e.g., "রাস্তার আলো / Streetlight")
  - Mapped department
  - Citizen-facing description (one line)
  - Status pill
- Click row → opens category editor.

#### Add category

- **`admin-city-categories-button-add`** — at the bottom of the list.
  - **Label (BN):** "+ নতুন ক্যাটাগরি"
  - **Label (EN):** "+ Add category"

### Mapping panel (below both lists)

- **`admin-city-mapping-panel`** — read-only summary.
- A simple matrix: rows = categories, columns = departments, cells = checkmarks where a category is mapped to a department.
- Cells are editable inline; tapping a cell toggles the mapping.

### Primary action

- **`admin-city-departments-button-next`** — sticky-bottom, full-width.
  - **Label (BN):** "পরবর্তী: ওয়ার্ড ও সীমানা"
  - **Label (EN):** "Next: Wards & boundaries"
  - Tap → routes to Wards & Boundaries (see spec).
  - Disabled until at least 1 department and 1 category exist.

### Secondary actions

- **`admin-city-departments-link-skip`** — text link.
  - **Label (BN):** "পরে সম্পন্ন করুন"
  - **Label (EN):** "Complete later"

## Behavior

### Department editor (inline or modal)

- Click department row → inline expansion with:
  - Name fields (Bangla, English)
  - Contact email + phone
  - Status toggle
  - "মুছুন / Delete" button (with confirmation modal — requires hardware key if any tickets are mapped)
- Inline editor auto-saves on blur.

### Category editor

- Click category row → inline expansion with:
  - Name fields (Bangla, English)
  - Department dropdown (single-select)
  - Icon picker (curated set of 12 line icons)
  - Citizen-facing description (200 chars, Bangla + English)
  - Status toggle
  - "মুছুন / Delete" button

### Mapping toggle

- Cells in the mapping panel toggle the assignment on tap. Changes auto-save.

### Template reset

- "Replace with Dhaka template" → confirmation modal: "ঢাকার কনফিগারেশন লোড করলে আপনার সম্পাদনা মুছে যাবে / Loading Dhaka config will overwrite your changes."
- On confirm: full template is loaded.

### Auto-save

- Edits auto-save every 30s. Inline indicator shows status.

### Validation

- Each department must have at least one category mapped. Unmapped departments show a warning: "কোনো ক্যাটাগরি ম্যাপ করা হয়নি / No categories mapped."

### Hardware-key requirement

- Delete actions and template reset require the hardware key.

---

## States

### Default (template loaded)

8 departments and 6 categories visible from Dhaka template; all mapped.

### Editing (inline expansion open)

One row expanded; form fields visible.

### Saving

"Saving…" indicator.

### Saved

"Saved" indicator.

### Validation warning

Yellow warning on unmapped departments.

### Delete confirmation

Hardware-key modal opens; row dimmed.

### Network failure

Toast; unsaved changes queued.

---

## Success

Aamir adjusts 2 department names to match Chattogram's terminology, adds 1 new category (specific to Chattogram's geography), confirms mappings, taps Next. He is on the Wards & Boundaries step in under 5 minutes.

**Emotional outcome:** Aamir feels the platform **respects Dhaka's learnings** — he is not starting from scratch. He is configuring, not building.

## Open Questions

- **Custom icons** — can Aamir upload custom category icons? **Default for v1: no, curated set of 12.** Custom icons are a v1.1 enhancement.
- **Department head count** — should Aamir specify how many dispatchers / crews each department has? **Default for v1: no.** Crew provisioning lives in User Provisioning (next page in this flow).
