# Wards & Boundaries

**Route:** `/admin/cities/{city_id}/setup/wards`
**Scenario:** Aamir the Administrator — Sets up Chattogram (screen 5 of 7)
**Purpose:** Define the geographic wards of the city — their boundaries, codes, names, and which dispatcher covers which wards.

---

## User Context

Aamir is configuring Chattogram. He needs to import or draw the city's wards. Dhaka's 36 wards are pre-loaded as a template (Chattogram will have ~41). For each ward, Aamir sets the name, code, and the dispatcher responsible.

## Behavior

### GeoJSON import

- File picker accepts .geojson files.
- Each feature must have properties: `code`, `name_bn`, `name_en`, `population`.
- On import: polygons are rendered; metadata is loaded into the list and detail panels.
- Errors (invalid GeoJSON, missing fields) are shown inline with a list of which wards failed.

### Map draw mode

- Click "Add ward" → cursor changes; user clicks polygon vertices.
- Click first vertex to close the polygon.
- After polygon closes: ward detail panel opens with empty metadata fields; user fills them in.

### Ward editing

- Click polygon vertex to drag (re-shape).
- Click polygon edge to add a vertex.
- Click polygon interior to drag the whole polygon.

### Auto-save

- Edits auto-save every 30s. Inline indicator shows status.

### Dispatcher assignment

- Dispatcher dropdown lists all dispatchers in this city.
- Selecting "—" (none) leaves the ward unassigned — tickets in this ward will appear in a queue for chief-dispatcher triage.

### Hardware-key requirement

- Delete actions and bulk operations require the hardware key.

### Map performance

- Wards > 100 trigger a "বড় শহর / Large city" mode that simplifies polygon rendering (less anti-aliasing, lower-resolution tiles).

## States

### Default (template loaded)

Dhaka template visible (36 wards); no ward selected; detail panel shows empty state.

### Ward selected

Detail panel populated; map flies to ward bounds.

### Drawing

Cursor in draw mode; vertices being placed.

### GeoJSON import in progress

Modal with progress bar.

### GeoJSON import error

Modal with list of failed wards + reasons.

### Validation warning

Ward with no dispatcher shows yellow warning.

### Deleting (hardware key required)

WebAuthn modal opens.

### Network failure

Toast; unsaved changes queued.

## Success

Aamir imports Chattogram's official ward GeoJSON (a .geojson file from the city corp), fills in missing names, assigns 5 dispatchers to 41 wards, taps Next. Total time: under 10 minutes.

**Emotional outcome:** Aamir feels the platform **respects official data** — he is not redrawing the city by hand; he is loading the city's own map.
