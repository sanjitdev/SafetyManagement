# Post-launch Adoption Dashboard

**Route:** `/admin/cities/{city_id}/adoption`
**Scenario:** Aamir the Administrator — Sets up Chattogram (screen 7 of 7)
**Purpose:** Give Aamir visibility into whether a city is being adopted — citizens reporting, dispatchers routing, crews fixing.

---

## User Context

Aamir has launched Chattogram. Two weeks in, he wants to see: are people actually using it? Are tickets moving? Is the city corp engaging? This page is **his signal that the launch is working** (or not).

---

## Content & Actions

### Page container

- **Page name:** `admin-city-adoption-page`
- **Language:** Bangla default.
- **Layout:** Single-column report layout. Cards stacked vertically. Print-friendly.
- **Width:** capped at 960px.

### Header

- **`admin-city-adoption-header`** — height 64px, sticky.
- **Left:** back arrow `<`. Routes to `/admin/cities/{city_id}`.
- **Center:** "গ্রহণ প্রতিবেদন / Adoption dashboard — {city name}."
- **Right:** date range picker (default: since launch).

### Hero stats (top of body)

- **`admin-city-adoption-hero-stats`** — four large stat cards.
- **Cards:**
  - "নিবন্ধিত নাগরিক / Registered citizens" — count + delta
  - "মোট রিপোর্ট গৃহীত / Reports received" — count + delta
  - "সমাধানের হার / Resolution rate" — percentage + delta
  - "গড় সমাধানের সময় / Avg time to resolve" — duration + delta

### Charts section

#### Adoption funnel

- **`admin-city-adoption-funnel`** — stacked funnel.
- Stages: "পরিদর্শন / Visit" → "নিবন্ধন / Registered" → "রিপোর্ট পাঠিয়েছেন / Submitted a report" → "২য় রিপোর্ট / 2nd report" → "প্রতিক্রিয়া জানিয়েছেন / Provided feedback."
- Each stage shows count + conversion rate from previous stage.

#### Daily activity

- **`admin-city-adoption-daily-chart`** — line chart.
- X-axis: dates since launch. Y-axis: counts.
- Three lines: reports submitted, reports resolved, citizens registered.

#### Geographic heatmap

- **`admin-city-adoption-heatmap`** — map showing report density per ward.
- Color gradient from "no reports" to "high activity."
- Hover a ward → tooltip with count.

### Engagement signals

- **`admin-city-adoption-engagement`** — three signal cards.
- **Signals:**
  - "কর্মী সক্রিয়তা / Staff activity" — % of dispatchers / crews who logged in this week.
  - "নাগরিক ধারাবাহিকতা / Citizen retention" — % of citizens who submitted a 2nd report within 30 days.
  - "ক্রু প্রতিক্রিয়া সময় / Crew response time" — median time from "assigned" to "started work."

### Health flags

- **`admin-city-adoption-health-flags`** — a list of warnings.
- **Examples:**
  - "৩ জন ডিসপ্যাচার গত ৭ দিনে লগইন করেননি / 3 dispatchers haven't logged in for 7 days."
  - "৫০টি টিকিট ৭ দিনের বেশি বরাদ্দহীন / 50 tickets unassigned for 7+ days."
  - "ওয়ার্ড ২২-এ গত ১৪ দিনে কোনো রিপোর্ট নেই / Ward 22 has had no reports in 14 days."
- Each flag links to the relevant dashboard / detail page.

### Export controls

- **`admin-city-adoption-button-export-pdf`** — primary button.
- **`admin-city-adoption-button-export-csv`** — secondary text link.

---

## Behavior

### Date range selection

- Default: since launch date. Options: last 7 days, last 30 days, since launch, custom.

### Real-time vs. snapshot

- This page is a **snapshot** — does not poll. Refreshes on date-range change.

### Drill-down

- Click any chart segment or ward heatmap cell → opens the relevant ticket list / dashboard.

### Comparison

- "ঢাকার সাথে তুলনা / Compare with Dhaka" toggle overlays Dhaka's metrics on the same charts (as a dashed line / different color).

### Print stylesheet

- Hides interactive chrome; charts render in print mode.

### Accessibility

- Charts have table siblings for screen-readers.

---

## States

### Default (since launch)

Funnel, daily chart, heatmap, engagement signals, health flags all populated.

### Filtered (custom range)

Charts and stats refresh to match range.

### Empty (low activity)

Funnel shows early stage only; charts show low counts; health flags surface concerns.

### Loading

Skeleton charts + stat cards.

### Exporting

Spinner on the export button; modal "PDF তৈরি হচ্ছে / Preparing PDF…"

### Comparison active

Dhaka metrics visible as overlay.

---

## Success

Aamir pulls up the dashboard two weeks after Chattogram's launch. He sees 12,000 registered citizens, 2,800 reports, 78% resolution rate, and 3 health flags. He clicks the "no reports in Ward 22" flag, drills into that ward, sees it's because the dispatcher is on leave — assigns a temp. Total time: 5 minutes.

**Emotional outcome:** Aamir feels the platform **makes adoption legible**. He is not guessing whether Chattogram is working — the signals are visible, the flags are actionable.

---

## Open Questions

- **Cross-city comparison** — should Aamir be able to compare all cities side-by-side? **Default for v1: yes, on each city's adoption page** (toggle to overlay another city). Cross-city table view is a v1.1 enhancement.
- **Predictive flags** — should the platform predict which wards will go silent next? **Default for v1: no.** Predictive analytics is a v2 feature.
