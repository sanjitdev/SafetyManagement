# Admin Console Login

**Route:** `/admin/login`
**Scenario:** Aamir the Administrator — Sets up Chattogram (screen 1 of 7)
**Purpose:** Authenticate Aamir into the admin console — a hardened login distinct from the citizen and dispatcher surfaces.

---

## User Context

Aamir is logging into the back office. He works for the central CityFix operations team (not city-corp). His login is gated by a hardware key (YubiKey or similar) plus password. This page is a security boundary, not a friendly greeting.

---

## Behavior

### Authentication flow

1. User enters Admin ID + password.
2. User taps "Touch your key" → WebAuthn prompt appears.
3. User touches key → assertion is generated.
4. Tap Submit → app POSTs `{id, password, webauthn_assertion}` to backend.
5. **On 200 OK:** JWT stored; routes to `/admin/cities` (Cities Overview Dashboard).
6. **On 401:** inline error "পরিচয় বা কী যাচাই ব্যর্থ / Identity or key check failed."
7. **On 423 (locked after N failures):** inline error with lockout duration.
8. **On WebAuthn failure:** inline error "কী শনাক্ত করা যায়নি — আবার চেষ্টা করুন / Key not recognized — try again."

### Session duration

- Admin sessions expire after 4 hours of inactivity. Re-auth required.

### Audit logging

- Every admin login (success or failure) is logged with timestamp, IP, and user agent.

### Keyboard behavior

- `Enter` submits. The hardware key button is not keyboard-triggerable.

### Session check

- On page load: if a valid admin JWT exists, skip to `/admin/cities`.

## States

### Default (no input)

Empty form; Submit disabled.

### Password only

Hardware-key button visible; Submit disabled.

### Both ready

Submit enabled.

### Hardware-key prompt active

WebAuthn modal visible on top of the page.

### Submitting

Spinner; all inputs disabled.

### Auth failed

Inline error above submit; password cleared.

### Locked

Inline error with countdown; Submit disabled.

### Already signed in

Page redirects to `/admin/cities`.

---

## Success

Aamir enters his credentials, taps his key, lands on the Cities Overview Dashboard. Time inside the login page: under 30 seconds.

**Emotional outcome:** Aamir feels the platform **takes his role seriously** — no shortcut paths, no marketing, no decorative chrome.

## Open Questions

- **Hardware-key requirement for v1** — is WebAuthn mandatory, or can admins opt in? **Default for v1: mandatory** for any admin with city-write permissions. Read-only admins may use password + TOTP.
- **IP allow-listing** — restrict admin logins to known IP ranges. **Default for v1: optional, configurable per admin.**
