# Cities Overview Dashboard

**Route:** `/admin/cities`
**Scenario:** Aamir the Administrator — Sets up Chattogram (screen 2 of 7)
**Purpose:** Give Aamir a single overview of every city on CityFix — what stage each one is at, what's healthy, what needs attention.

---

## User Context

Aamir logs in and lands here. He wants to see the health of every city at a glance: is Dhaka humming? Is Chattogram in setup? Is Sylhet waiting? This page is **his map of the country**.

---

## Content & Actions

### Page container

- **Page name:** `admin-cities-page`
- **Language:** Bangla default.
- **Layout:** Two-column desktop (left: city list, right: detail pane). Stacks vertically on tablet.
- **Width:** full-viewport on desktop, capped at 1440px.

### Header

- **`admin-cities-header`** — height 64px, sticky.
- **Left:** CityFix logo + "প্রশাসক / Admin" label.
- **Center:** empty.
- **Right:** avatar menu (Aamir's name, sign out).
- **At phone viewports (≤540px):** the header wraps to two rows — the menu button and the search field share row 1, and the action controls (notifications, date range, language, theme, avatar menu) sit right-aligned on row 2. The avatar menu remains the last, rightmost control; nothing is hidden.

### City list (left column)

- **`admin-cities-list`** — vertical scroll.
- **`admin-cities-row-{city_id}`** — each row:
  - City name + code (e.g., "চট্টগ্রাম · CHT / Chattogram · CHT")
  - Stage pill — one of: "লাইভ / Live", "সেটআপ / Setup", "পরিকল্পিত / Planned", "স্থগিত / Paused"
  - Active users (last 7 days)
  - Tickets opened (last 7 days)
  - Tickets resolved (last 7 days)
  - Resolution rate (last 7 days)
- Sorted by stage (Live first, then Setup, then Planned, then Paused) → name (A→Z).
- Click row → detail pane updates.

### Detail pane (right column)

- **`admin-cities-detail-pane`** — empty by default with copy "একটি শহর নির্বাচন করুন / Select a city."
- When a row is selected: shows city overview, recent activity, key configuration links.

#### City overview block

- **`admin-cities-detail-overview`** — labeled rows:
  - **Stage** — pill
  - **Population coverage** — e.g., "ঢাকা উত্তর সিটি কর্পোরেশন — ৩০ লক্ষ / Dhaka North City Corporation — 3.0M"
  - **Wards configured** — "৩৬ / ৩৬ (১০০%) / 36 / 36 (100%)"
  - **Departments configured** — "৮ / ৮ / 8 / 8"
  - **Languages active** — "বাংলা, English / Bangla, English"
  - **Launched on** — date

#### Configuration links

- **`admin-cities-link-edit-basic`** — text link.
  - **Label (BN):** "মৌলিক তথ্য সম্পাদনা"
  - **Label (EN):** "Edit basic info"
  - Tap → routes to City Setup Basic Info (see spec).
- **`admin-cities-link-departments-categories`** — text link.
  - **Label (BN):** "বিভাগ ও ক্যাটাগরি"
  - **Label (EN):** "Departments & categories"
  - Tap → routes to Departments & Categories (see spec).
- **`admin-cities-link-wards`** — text link.
  - **Label (BN):** "ওয়ার্ড ও সীমানা"
  - **Label (EN):** "Wards & boundaries"
  - Tap → routes to Wards & Boundaries (see spec).
- **`admin-cities-link-users`** — text link.
  - **Label (BN):** "কর্মী ব্যবস্থাপনা"
  - **Label (EN):** "User provisioning"
  - Tap → routes to User Provisioning (see spec).
- **`admin-cities-link-adoption`** — text link.
  - **Label (BN):** "গ্রহণ পরিসংখ্যান"
  - **Label (EN):** "Adoption dashboard"
  - Tap → routes to Post-launch Adoption Dashboard (see spec).

#### Primary action

- **`admin-cities-button-launch`** — primary button (visible only if stage = Setup).
  - **Label (BN):** "শহর লাইভ করুন"
  - **Label (EN):** "Launch city"
  - Tap → opens a launch checklist modal; on confirm, city stage transitions to Live.

#### Recent activity strip

- **`admin-cities-recent-activity`** — small vertical list of last 10 admin actions in this city.
- Each entry: action + actor + timestamp.

### Add city action

- **`admin-cities-button-add`** — primary button at the top of the city list.
  - **Label (BN):** "নতুন শহর যোগ করুন"
  - **Label (EN):** "Add new city"
  - Tap → opens the City Setup Basic Info page in "new" mode (see spec).

## Behavior

### Real-time updates

- Polls every 30s (admin pace is slower than operations).
- New activity entries animate in.

### Stage transitions

- Planned → Setup: triggered when Aamir saves the city's basic info.
- Setup → Live: triggered by the Launch button after a checklist passes.
- Live → Paused: triggered manually (e.g., for maintenance).

### Search / filter

- A search input above the city list filters by name or code.

### Click row

- Click row → detail pane updates. URL updates to `/admin/cities/{city_id}` (so the selection is shareable).

### Hardware-key re-prompt

- For destructive actions (Launch, Delete city, Edit ward boundaries), the app re-prompts for the hardware key.

---

## States

### Default

City list visible; detail pane shows empty state.

### City selected

Detail pane populated with the city's data.

### No cities yet

Centered empty state: "কোনো শহর কনফিগার করা হয়নি / No cities configured." With an "Add new city" CTA.

### Launching (in flight)

Spinner on the Launch button; row's stage pill animates.

### Launch failed

Inline error modal with reason (e.g., checklist incomplete).

### Hardware-key required

WebAuthn modal opens; main page dims.

---

## Success

Aamir logs in, scans his 3 cities, opens Chattogram (currently in Setup), clicks "Edit basic info" to start work. Time on this page: 30 seconds.

**Emotional outcome:** Aamir feels **oriented** — the platform tells him where each city stands, where to click next, and what needs his attention.

## Open Questions

- **Cross-city search** — should Aamir be able to search a specific ticket across cities? **Default for v1: no.** A global ticket search is a v1.1 enhancement.
- **City comparison** — side-by-side stats across cities. **Default for v1: no.** Each city's adoption dashboard provides internal comparison.
