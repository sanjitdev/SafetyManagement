# City Activity Feed (return visit)

**Route:** `/feed` *(also exposed via `/home?view=feed` as a tab on the Home top bar)*
**Scenario:** Rahim the Reporter — Reports a broken streetlight (screen 13 of 14)
**Purpose:** Power-user behavior — give Rahim a focused, scrollable view of what's moving across the city.

> **Phase B (2026-10-04):** Activity Feed keeps its full-list pattern but renders inside a **centered content column (max-width 720px) below a top bar** at all viewports. The filter chip row stays sticky at the top of the column. On large viewports the map region from Home is hidden — this is the list-only power-user view. On medium / phone widths the page is identical (the content column shrinks, the filter row wraps). See `_progress/00-design-log.md` for the re-skin.

---

## User Context

Rahim returns to the app later (his 5th or 10th open of the day). He wants to see motion — what's been reported, what's been fixed. He scrolls the feed for 30 seconds while waiting for his tea. This page is the **proof of life** for the platform.

---

## Content & Actions

### Page container

- **Page name:** `city-activity-feed-page`
- **Language:** Bangla default.
- **Layout:** Web-first. Top bar (`--header-height-desktop` at large, `--header-height-mobile` at medium) + a **centered content column (max-width 720px)** on a calm neutral surface. Inside the column: page title block + sticky filter chip row + scrollable feed list. No map region here — this is the list-only power-user view.

### Top bar

- **`feed-topbar`** — same surface and height tokens as the rest of the app's top bars.
- **`feed-brand`** (left) — CityFix wordmark + breadcrumb "শহরের সর্বশেষ / What's happening".
- **`feed-link-home`** (right) — text link "হোম / Home" (back to map + side panel).
- **`feed-avatar`** (right, far) — circular avatar (initials), 32px.

### Filter chips (sticky, top of content column)

- **`feed-filter-row`** — horizontal row inside the content column, sticky below the top bar. Wraps to two lines on narrow viewports.
- **Chips:**
  - "All / সব" (default, primary fill)
  - "Open / খোলা"
  - "In progress / চলমান"
  - "Resolved / সমাধান"
  - "Resolved today / আজ সমাধান"
- Tap a chip → re-filters feed. Selected chip = primary fill + white text.

### Feed list

- **`feed-list`** — vertical scroll of activity items.
- **`feed-item-{ticket_id}`** — each row:
  - Thumbnail (small, ~56×56)
  - Category icon + label
  - Ward + age label
  - Status pill (color-coded)
  - Brief description (≤40 chars)
- Pagination: 20 items per page; infinite scroll; "Load older" trigger at bottom.
- Pull-to-refresh at the top.
- **New items at top** marked with a small "new" badge that fades after 5 seconds.

### Empty state

- If no reports match the filter: centered message "কোনো রিপোর্ট নেই" / "No reports." With a "Be the first to report" link if "All" filter shows empty.

---

## Behavior

### Real-time updates

- Feed subscribes to the server for new items via polling (15s) or WebSocket (v2).
- New items animate in at the top of the list.

### Tap row

- Tap `feed-item-{ticket_id}` → `/tickets/{id}` (the public ticket detail page — see `/tickets/:id` spec, deferred to v2 sweep).

### Back navigation

- Back arrow → `/home` (the map view).

---

## States

### Default

20 items, most recent at top. Filter "All" selected.

### Filtered

List narrows to match the selected filter.

### New item arrived

New item animates in at the top with a "new" badge.

### Loading more (older)

Skeleton items below the current list during pagination.

### Empty (no matches)

Centered message + optional CTA.

---

## Success

Rahim scrolls the feed, sees 3–5 fresh items in the last hour, taps one to see what's happening, sees a real fix in progress (citizen's photo + crew dispatched), returns to the feed. He feels **the city is moving**.

**Emotional outcome:** This page is the *trust engine* of CityFix. If the feed is rich and honest, Rahim is a daily user. If it ever feels stale or fake, he churns.
