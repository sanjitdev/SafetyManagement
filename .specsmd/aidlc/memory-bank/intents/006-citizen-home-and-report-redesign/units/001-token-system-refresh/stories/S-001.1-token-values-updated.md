# Story S-001.1 — Token values updated to new palette

## As a

Citizen visiting any redesigned CityFix surface (home or report flow)

## I want

The visual palette to use high-contrast navy + accent blue (the
"Accessible & Ethical" civic-service register)

## So that

The app looks like a professional civic service, not a startup
mockup, and every text/control passes WCAG-AA contrast.

## Acceptance Criteria (BDD)

### Given
The current `tokens.css` defines the old color tokens
(`--color-primary: #2C5282`, `--color-accent: ...`, etc.) and every
component in the app reads those tokens by name.

### When
The construction agent updates the hex values of the color, surface,
and ink tokens in `tokens.css` to the new palette spec (slate-900
navy, sky-700 accent, slate-50 page, white card, slate-100 raised,
slate-200 sunken, slate ink ramp, slate-200/300 border, red-600
destructive).

### Then
- Every component in `app/home/`, `app/report/`, and
  `app/report/[id]/submitted/` renders with the new colors.
- No per-component code change is required.
- `npx tsc --noEmit` is clean.
- All 287 Vitest unit tests pass.
- The default light theme and `.theme-hc` high-contrast theme both
  pass WCAG-AA contrast (≥ 4.5:1 body, ≥ 3:1 large text and
  non-text controls), verified by axe-core.

### And
- Token **names** are unchanged (verified by `git diff` showing
  only value changes on color tokens).
- The Playwright mockup baselines fail by design (the new palette
  changes every surface); the construction agent regenerates them
  in Bolt 006-002 and surfaces the diff in the PR.

## Story Notes

- This is the **foundation story**; Units 002, 003, 004 cannot land
  until this one is merged.
- The new palette values come from the ui-ux-pro-max "Accessible &
  Ethical" recommendation, adapted to CityFix's existing token
  names.
- `.theme-hc` overrides may need a small re-tune; if so, the
  construction agent adjusts only the override values, never the
  base names.
