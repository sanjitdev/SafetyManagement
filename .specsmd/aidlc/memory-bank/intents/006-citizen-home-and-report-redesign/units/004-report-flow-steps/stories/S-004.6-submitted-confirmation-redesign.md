# Story S-004.6 — Submitted confirmation redesign (FR-9)

## As a

Citizen who just submitted a report

## I want

A clean success surface: a big green checkmark, a one-line
confirmation, my reference ID (copyable), a 3-step "What happens
next" list, and two actions ("View report" / "Back to home")

## So that

I leave the flow feeling heard and informed — not with the
impression that my report vanished into a void.

## Acceptance Criteria (BDD)

### Given
The current `/report/[id]/submitted` page shows a small check
icon and a "Thank you" message.

### When
The construction agent redesigns the page to:
- Large green checkmark (lucide `CheckCircle2`, 96dp), centered.
- H1: "আপনার রিপোর্ট গ্রহণ করা হয়েছে" ("Your report has been
  received"), `--text-display-md` on mobile,
  `--text-display-lg` on desktop.
- Reference ID in mono font, copyable to clipboard via a
  "Copy" button that flashes a "Copied" toast for 1.5s.
- "What happens next" three-step list (Bangla):
  1. আমরা আপনার রিপোর্ট পর্যালোচনা করব (We will review your
     report)
  2. প্রাসঙ্গিক বিভাগে রাউট করা হবে (It will be routed to the
     relevant department)
  3. আপডেটের জন্য নোটিফিকেশন পাবেন (You will receive updates
     via notification)
- Two actions: "View report" (primary) and "Back to home"
  (secondary).

### Then
- The reference ID is selectable (text can be highlighted) and
  has a "Copy" button. On click, the ID is copied to the
  clipboard and a "Copied" toast appears for 1.5s. The toast
  has `aria-live="polite"`.
- The page is the only place the citizen sees a "submission
  succeeded" state — subsequent visits to
  `/report/[id]/submitted` for the same id do not re-show the
  success animation (the success animation is gated on a
  client-side flag set at first visit only).
- The H1 uses the display type scale.
- "View report" routes to `/tickets/<id>`; "Back to home"
  routes to `/home`.
- axe-core shows zero serious or critical issues.

## Story Notes

- Per Checkpoint 2 default: the "What happens next" list is in
  Bangla only; the English toggle reveals the same list in
  English when active.
- The success animation is a 1.2s scale-in of the checkmark
  (CSS transition, `transform: scale(0.8) → scale(1)`); collapses
  to instant under `prefers-reduced-motion`.
- The "Copied" toast is a `<div role="status" aria-live="polite">`
  that appears for 1.5s and then fades out.
