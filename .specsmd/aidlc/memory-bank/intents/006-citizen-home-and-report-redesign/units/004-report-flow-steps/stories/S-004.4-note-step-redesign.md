# Story S-004.4 — Note step redesign (FR-7)

## As a

Citizen adding an optional note to my report

## I want

A clearly-labeled textarea with a visible character counter
("0 / 280") and a short helper text, so I know what to write and
how much room I have

## So that

I can add context that helps the dispatcher route my report
without typing more than the system can handle.

## Acceptance Criteria (BDD)

### Given
The current `/report/note` page shows a textarea with a
placeholder-only label and no character counter.

### When
The construction agent redesigns the page to:
- Visible label above the textarea: "কিছু বলতে চান?" ("Anything
  to add?")
- Helper text below the field: "ঐচ্ছিক — ২৮০ অক্ষর পর্যন্ত"
  ("Optional — up to 280 characters")
- Character counter at the bottom-right of the field (e.g.
  "127 / 280"), `aria-live="polite"`.
- Big "Continue" primary button (full-width on mobile).
- Textarea auto-grows to 5 lines, then scrolls internally.

### Then
- 280-char hard limit with a visible error state if exceeded
  (red border + error message).
- The counter is announced to screen readers via
  `aria-live="polite"`.
- The textarea auto-grows up to 5 lines, then scrolls internally.
- "Continue" is always enabled (note is optional — the citizen
  can skip the step).
- axe-core shows zero serious or critical issues.

## Story Notes

- The Bangla "২৮০" is the digit "280" in Bengali numerals; the
  i18n registry handles the rendering.
- The character limit is enforced at the form level (no server
  roundtrip) so the error state is instant.
