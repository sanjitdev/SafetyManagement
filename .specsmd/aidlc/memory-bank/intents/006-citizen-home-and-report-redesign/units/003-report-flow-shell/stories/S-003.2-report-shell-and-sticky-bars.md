# Story S-003.2 — ReportShell + sticky top/bottom bars

## As a

Citizen walking through the 5-step report flow

## I want

Every step page to share the same shell: a sticky top bar with the
brand mark, "Submit a report" badge, step indicator, and language
toggle; a sticky bottom bar on mobile with Back / Continue; an
in-card action row on desktop

## So that

I always know where I am, where to go next, and how to get back
— without having to relearn the layout on each step.

## Acceptance Criteria (BDD)

### Given
The `/report/*` layout currently renders each step page without a
shared shell.

### When
The construction agent wraps every step page in
`<ReportShell>` (and the layout in `app/report/layout.tsx` if
applicable) so the shell is rendered once at the layout level.

### Then
- The shell includes:
  - **Top bar (sticky)**: brand mark (left), "Submit a report"
    badge (next), `<StepIndicator>` (middle / right), language
    toggle (right). The bar is 56dp tall.
  - **Body**: each step page's content (cards, maps, fields).
  - **Bottom bar (sticky, mobile only)**: Back / Continue
    buttons, full-width, ≥ 56dp tall. Disabled "Continue" has
    50% opacity and `aria-disabled="true"`.
  - **Action row (desktop, in-card)**: Back / Continue buttons
    inside the step's main card.
- The "Back" button is always reachable without scrolling on
  mobile (sticky bottom).
- The "Continue" button is disabled until the current step's
  required field is filled; the disabled state is announced via
  `aria-disabled`.
- A Vitest unit test covers the shell: (a) renders the top bar,
  (b) renders the bottom bar on mobile, (c) renders the in-card
  action row on desktop, (d) the disabled "Continue" state.

## Story Notes

- The shell accepts `step`, `totalSteps`, `onBack`, `onContinue`,
  `canContinue`, `children` props.
- The "Submit a report" badge is a small text element (not a
  link) — it's a status indicator, not a navigation target.
- The language toggle reuses the existing language-switch
  primitive (not redesigned by this intent).
