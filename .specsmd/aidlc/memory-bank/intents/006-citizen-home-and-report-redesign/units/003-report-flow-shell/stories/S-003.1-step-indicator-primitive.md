# Story S-003.1 — StepIndicator primitive

## As a

Library author building the report flow shell

## I want

A reusable `<StepIndicator>` component that accepts
`steps={["Location", "Photo", "Category", "Note", "Summary"]}`
and `current={2}` and renders either 5 numbered circles connected
by a line, or a "Step 2 of 5" text label

## So that

Every step page shows the citizen where they are and what's left,
and the component handles the responsive collapse automatically.

## Acceptance Criteria (BDD)

### Given
The report flow has 5 steps: Location, Photo, Category, Note,
Summary.

### When
`<StepIndicator steps={steps} current={currentStep} />` is
rendered at the top of the report shell.

### Then
- At ≥ 768px viewport: 5 numbered circles connected by a 2dp
  line. Current step is filled `--color-accent` with white number;
  completed steps are filled `--color-primary` with a checkmark
  icon; future steps are filled `--color-surface-raised` with
  `--color-ink-tertiary` number. The line fills left to right
  as the citizen progresses (animated, respects
  `prefers-reduced-motion`).
- At < 768px viewport: collapses to a single "Step {N} of {M}"
  text label. No numbered circles. The shell stays under 56dp
  tall.
- The component has a Vitest unit test covering: (a) default
  rendering, (b) the `current` prop changes the highlight, (c)
  the `completed` state shows checkmarks, (d) the responsive
  collapse.
- axe-core: the indicator has a `role="progressbar"` with
  `aria-valuenow={currentStep}`, `aria-valuemin={1}`,
  `aria-valuemax={steps.length}`.

## Story Notes

- The checkmark icon is from lucide-react (`Check`).
- The line animation uses CSS transition (no JS animation lib).
- The component accepts a `labels` map for i18n; default labels
  are English but the report flow passes Bangla labels from
  `lib/i18n/keys.ts`.
